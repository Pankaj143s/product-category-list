# 🛍️ Product Category List – Qi Theme Inspired UI

A responsive and interactive product category list UI, inspired by the Qi Theme's Product Category List widget. This project replicates the hover animations and layout to showcase product categories elegantly.

> 🚀 **Live Preview**: [https://pankaj143s.github.io/product-category-list/](https://pankaj143s.github.io/product-category-list/)

---

## ✨ Features

- **Hover Animations**: Smooth and engaging hover effects on category cards.
- **Responsive Design**: Optimized for desktops, tablets, and mobile devices.
- **Clean Layout**: Minimalistic design focusing on product categories.
- **Inspired by Qi Theme**: Replicates the style of the Qi Theme's Product Category List widget.

- **HTML5**: Markup structure.
- **CSS3**: Styling and animations.
- **JavaScript**: Interactivity (if applicable).
